자사몰 시안

Photoshop · CSS · HTML

프로젝트 소개

자사몰 메인 화면을 기준으로 브랜드의 첫인상과 주요 상품 진입 흐름을 정리한 웹 시안입니다. 방문자가 상품군과 프로모션을 빠르게 파악할 수 있도록 비주얼 영역, 카테고리, 추천 상품, 이벤트 배너의 우선순위를 구성했습니다.

작업 포인트

  • 메인 비주얼과 상품 정보가 한 화면에서 자연스럽게 이어지도록 레이아웃을 설계했습니다.
  • Photoshop으로 비주얼 톤을 정리하고 HTML/CSS로 기본 퍼블리싱 구조까지 연결했습니다.
  • 쇼핑몰 메인에서 필요한 브랜드 인지, 탐색, 구매 진입 흐름을 함께 고려했습니다.
